# 🙋 허수영 · 자기소개 페이지 (Streamlit)

KDN 풀스택 바이브코딩 3기 실습 — Streamlit으로 만든 개인 자기소개 웹앱입니다.

## 🖥️ 실행 방법

### 1. 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 앱 실행

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 자동 접속됩니다.

## 📁 파일 구조

```
kdn-vivecoding3/
├── app.py            # Streamlit 메인 앱
├── requirements.txt  # 의존성 패키지
└── README.md         # 프로젝트 설명
```

## ✨ 주요 기능

- 🎨 다크 그라데이션 테마 (커스텀 CSS)
- 👤 프로필 · 소개 섹션
- 🛠️ 기술 스택 배지
- 📅 경력 타임라인
- 📬 연락처
- 🎭 성격 · 관심사 · 한마디 카드
- 🎬 Lottie 애니메이션 (선택적)

## 🛠️ 기술 스택

- **Python 3.10+**
- **Streamlit** — 메인 프레임워크
- **streamlit-lottie** — 애니메이션
- **requests** — Lottie JSON 로드
